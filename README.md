# KOBOK – instalator

Wersja **0.62.3** · dwupanelowy menedżer plików dla macOS 14 i nowszego.

**[Pobierz Kobok.pkg](https://github.com/sygnaturazdrowia/kobok-instalator/raw/main/Kobok.pkg)**

## Instalacja

1. Otwórz pobrany plik **Kobok.pkg** (folder Pobrane rzeczy).
2. Jeśli macOS napisze, że nie może sprawdzić programu: **Ustawienia systemowe → Prywatność i ochrona**,
   na dole przy „Kobok.pkg” kliknij **Otwórz mimo to** i potwierdź hasłem Maca.
3. W Instalatorze: **Kontynuuj → Instaluj** (hasło Maca). KOBOK sam trafi do folderu **Aplikacje**.
4. Uruchom KOBOK z Aplikacji albo z Launchpada.

Nowsza wersja instaluje się tak samo – podmienia poprzednią.
